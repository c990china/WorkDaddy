# WorkDaddy 改进建议（2026-09-07 代码审查）

> 来源：对 c990china/WorkDaddy 仓库的远程代码审查（README、CI、.gitignore、
> daemon.js / inject.js 文件头与仓库结构）。
> 状态列：⬜ 未开始 / 🔄 进行中 / ✅ 已完成。每条修完请打勾。

## P0 — 应立即处理

1. **⬜ 发行二进制不应入库**：`release/windows/*.exe`（各约 28 MB）与
   `release/macos/*.dmg`（各约 2.7 MB）被提交进 git，永久撑大仓库与克隆体积。
   CI 已通过 `softprops/action-gh-release` 把产物挂到 GitHub Release，仓库内副本是冗余的。
   建议：`.gitignore` 增加 `release/`（保留 `.gitkeep`），`git rm --cached` 后仅靠 Release 分发。

2. **⬜ `.DS_Store` 入库**：`scripts/assets/dmg-layout/*.DS_Store` 虽在
   `.gitignore` 中（后加的规则），但仍是已跟踪文件。`git rm --cached` 移除。

3. **⬜ 本地 HTTP API / CDP 无鉴权与 Origin 校验**：`127.0.0.1:47832` 暴露
   账号切换/删除、模型配置等敏感接口，浏览器中任意网页可向其发 CSRF 式请求。
   建议：非空且非 `http://127.0.0.1:47832` 的 Origin 一律拒绝；CDP 端口
   （`--remote-debugging-port`）无认证，考虑启动时生成随机 token 或至少
   在威胁模型中明确说明。

4. **⬜ daemon.js 内硬编码开发者路径**：`/Users/h/.workbuddy/binaries/.../ws`
   是某位开发者的家目录，其他机器上不成立。应改用 `os.homedir()` 拼接或删除。

## P1 — 可维护性

5. **⬜ 无 package.json / 无 lint / 无测试**：inject.js 注释里写明决策逻辑
   保持纯函数"以便回归测试"，但仓库里没有任何测试运行器。
   建议：加 `package.json`（`npm test` / `npm run lint`），用 `node --test`
   对 classifySessionHealth / classifyAutoContinueReply 等纯函数做快照测试，
   并在 CI 中执行——这是防 WorkBuddy 界面升级破坏选择器的主要防线。

6. **⬜ 巨型单文件**：`inject.js`（685 KB）、`daemon.js`（392 KB）、
   `theme-patches.js`（83 KB）、`win-launcher.js`（77 KB）。
   daemon 已按模块拆分（lib.js / credit-*.js / session-db.js 等，良好）；
   重点是 inject.js——把面板各 tab（账号/主题/会话/模型）拆成独立脚本，
   构建时拼接。

7. **⬜ 只有 Windows 构建 CI**：仅有 `.github/workflows/build-win.yml`，
   macOS dmg 无自动构建。加 macOS runner，两个平台 tag 时自动构建+验证+发布。

8. **⬜ 版本号单一来源**：CI 用 `grep "DAEMON_VERSION"` 从 daemon.js 提取版本，
   PS1 里再 grep 一次。建议集中到单一 `version` 文件或 package.json，各处读取。

9. **⬜ 构建逻辑跨四种语言重复**：`build-mac-dmg.sh` / `build-win-zip.sh` /
   `build-win-installer.ps1` + `.cmd` / `.vbs` 包装。建议收敛为一个 Node 构建脚本。

## P2 — 文档与打磨

10. **⬜ README 克隆地址过期**：`git clone https://github.com/babygoton/WorkDaddy.git`
    与当前仓库 `c990china/WorkDaddy` 不符（0.6.8 变更日志也证实改过名）。修正。

11. **⬜ 英文 README 滞后**：`README_en.md`（6.6 KB）约为中文版（12.4 KB）一半，
    明显落后。同步一遍或标注滞后章节。

12. **⬜ 版本历史埋在 daemon.js 头部注释**：抽成 `CHANGELOG.md` 供用户查阅；
    代码内的"改动即递增"纪律保留。

13. **⬜ 本地账号备份明文存 token**：导出用 AES-256-GCM（好），但本机备份目录
    是明文。建议收紧目录权限（0600/0700）并在威胁模型中说明。

## 明确不改的部分

- CDP 注入架构本身（零侵入、不改官方安装包）——合理。
- AGPL-3.0 许可与"与官方无隶属关系"声明。
- `AGENTS.md`（22 KB，对 AI 协作友好）。
- ws 依赖的多路径回退链、遥测默认开启但有明确开关。
